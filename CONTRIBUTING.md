# Contributing

Thanks for considering contributing to Frontline Tactics!

## Where do I go from here?

Look up what needs to be done in the [issues](https://github.com/djantche/frontline-tactics/issues).

If you've noticed a bug or have a feature request, [open an issue](https://github.com/djantche/frontline-tactics/issues/new). It's best to get confirmation on it before starting to work.

## Fork and create a branch

Fork the repository and create a branch with a descriptive name, for example `mobile-navbar-fix`.

## Setting up your local environment

Setup instructions can be found in the [README](README.md).

## Linting

The CI checks the formatting of your code. Run `npm run lint` to find problems, and `npm run lint:fix` to fix most of them.
